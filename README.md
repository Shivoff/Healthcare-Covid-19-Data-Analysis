# 🦠 COVID-19 India Dashboard (Excel-based)

This project presents a comprehensive **COVID-19 Dashboard** for India, created using **Microsoft Excel**. It showcases vaccination statistics, case trends, testing metrics, and state-wise COVID-19 impact through interactive visuals and slicers.

![image](https://github.com/user-attachments/assets/ae8a03c0-6e05-40d4-9352-5749b25445c0)


## 📊 Features

- **Vaccination Analysis**
  - By gender
  - By age group
  - Total first & second dose administered

- **Trend Analysis**
  - Monthly trends for total cases, deaths, recoveries, and vaccinations

- **Testing Analysis**
  - State-wise total tests
  - Positive rate vs testing volume

- **CFR vs Infection Rate**
  - Comparison of infection and fatality rates pre- and post-vaccination

- **State-wise COVID Impact Table**
  - Total cases
  - Death rate
  - Recovery rate
  - Testing efficiency

- **Interactive Slicers**
  - Filter by State, Year, and Month
